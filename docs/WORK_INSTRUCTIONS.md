## Block C: Git

1. Create `.gitignore` at the repo root and type in these patterns:
   ```
   .venv/
   __pycache__/
   *.egg-info/
   .pytest_cache/
   .ruff_cache/
   unity/client/[Ll]ibrary/
   unity/client/[Tt]emp/
   unity/client/[Oo]bj/
   unity/client/[Ll]ogs/
   unity/client/[Uu]ser[Ss]ettings/
   unity/client/.vscode/
   unity/client/*.csproj
   unity/client/*.sln*
   ```
   Why: everything listed is regenerated by Python, Unity, or the IDE. `Library` alone is thousands of files. `Assets`, `Packages`, and `ProjectSettings` stay tracked because they are the real project.
2. Run `git status` and read it before you stage anything. Confirm nothing under `Library`, `.venv`, or any cache folder is listed, and no `.csproj` files.
   Why: once a file is committed, ignoring it later does not remove it from history.
3. `git add -A` then `git commit -m "M0 tooling: Python package and Unity 6 URP 3D project"`.
4. Checkpoint: `git status` reports a clean tree, and `(git ls-files).Count` returns a number in the low hundreds at most, not thousands. A number in the thousands means the ignore file is not catching Unity.
